# AI Software Engineer Agent

An AI-assisted developer tool designed to analyze GitHub issues, retrieve relevant repository context, generate proposed code changes, run automated tests in Docker, and prepare pull-request summaries for developer review.

> **Original development year:** 2026  
> **Public portfolio reconstruction:** July 2026  
> **Current status:** Rebuilding the public repository from verified project materials

## Project Overview

The project explores how AI agents can assist with structured software-engineering workflows, including issue interpretation, repository-context retrieval, proposed code generation, automated testing, failure analysis, and developer-facing summaries.

## Technologies Listed for the Project

- Python
- FastAPI
- React
- LangChain
- OpenAI API
- GitHub API
- Docker
- Pytest
